腾讯云debian安装docker

由于腾讯云服务器无法访问 docker.com ，所以需要将使用 dokcer.com 的地方转换成使用腾讯云的镜像服务。

# Add Docker's official GPG key:
# 1. 更新系统包：
sudo apt-get update
# 2. 安装依赖包:
sudo apt-get install ca-certificates curl
# 3. 创建 keyrings 目录：
sudo install -m 0755 -d /etc/apt/keyrings
# 4. 下载并保存腾讯云的 GPG 密钥：
sudo curl -fsSL https://mirrors.cloud.tencent.com/docker-ce/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
# 5. 更改 GPG 密钥的权限：
sudo chmod a+r /etc/apt/keyrings/docker.asc

# 6. Add the repository to Apt sources(添加 Docker 仓库到 APT 源列表):
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://mirrors.cloud.tencent.com/docker-ce/linux/debian/ \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
# 7. 更新包列表：
sudo apt-get update
# 8. 安装 Docker
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-compose-plugin

我这里使用的是 debian 系统。 真心不建议使用 centos 的同学还守旧了。 激进派可以用 ubuntu， 稳定派就 debian。
